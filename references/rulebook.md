# 中文去 AI 腔规则表

## 1. 硬禁：优先删除或重写

这些结构的问题不在于语法错误，而在于模型过度偏爱“先否定、再升华”的论证姿势。

| 模式 | 默认处理 | 更自然方向 |
|---|---|---|
| 不是A，而是B | 重写 | B来自… / B建立在…之上 / 直接说B |
| 不仅A，更/而且B | 重写 | 分成两句，或只保留真正重要的一层 |
| 不只是A，更是B | 重写 | 直接陈述两项事实，不做升华 |
| 并非A，而是B | 重写 | 若非必要，删掉A，直接说B |
| 这不仅仅是… | 删除 | 直接写结果或变化 |
| 从A到B | 仅在真实范围/过程时保留 | 列具体阶段或直接说覆盖范围 |
| 三个高度对称的并列短语 | 打散 | 让信息有主次，不追求整齐 |
| 未来可期/新篇章/新动能 | 删除 | 写下一步动作或目标 |

## 2. 限频：可以出现，但不能成为段落骨架

重点观察：`在此基础上、同时、此外、然而、因此、进一步、逐步、持续、最终、核心、形成、构建、打造、推动、促进、提升、优化、实现、协同、沉淀、整合、支撑、承接`。

建议：同一个词在 1,000–2,000 字内不超过 1–2 次；同一自然段出现 3 个以上高风险词，整段重写。

## 3. 最容易显 AI 的组合

- `逐步沉淀……`
- `持续优化……能力`
- `进一步提升……效率`
- `最终形成……生态`
- `构建……闭环`
- `打造……平台`
- `形成长期壁垒`
- `核心能力与核心优势`
- `通过……实现……推动……`
- `围绕……依托……通过……形成……`

这类组合往往信息密度低，逻辑层级却过多。优先改为具体动作。

## 4. 常见替换方向（不是机械同义词表）

- 沉淀数据 → 积累/记录项目数据
- 沉淀关系 → 建立/维护合作关系
- 协同 → 共同使用 / 共同参与 / 共享 / 配合（按具体语义）
- 赋能 → 帮助 / 支持 / 缩短 / 降低 / 增加
- 底座 → 系统 / 基础设施 / 共用平台 / 数据层（明确是什么）
- 生态 → 合作网络 / 客户与合作方体系 / 业务关系（明确是什么）
- 壁垒 → 难以复制的资源、数据、流程或关系（写出具体项）
- 闭环 → 写清入口、转化、交付、复购等具体环节
- 提升效率 → 缩短时间 / 减少人工步骤 / 提高匹配成功率（若原文有依据）
- 优化能力 → 改进哪一项流程/模型/服务
- 形成平台能力 → 平台新增/具备什么具体功能

## 5. 节奏规则

AI 文本常见问题不是“句子太长”本身，而是句法过度整齐。

避免连续出现：
- 通过A，提升B；通过C，提升D；通过E，提升F。
- A负责X，B负责Y，C负责Z。
- 首先…其次…最后…（内容并不需要排序时）

允许：
- 长短句混合。
- 关键名词重复，不必为了避免重复强行换同义词。
- 某些段落只陈述事实，不加总结。
- 某些段落有明显主次，不强行“三点齐全”。

## 6. 文体豁免

法律、科研、技术文档中的真实逻辑连接不应为了“去 AI 味”被删掉。例如真正需要排除定义时，`不是A，而是B`可以保留；真正描述实验流程时，`从A到B`可以保留。

原则：禁的是修辞模板，不是逻辑关系。
