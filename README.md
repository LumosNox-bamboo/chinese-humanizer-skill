# Chinese Humanizer Skill

这是一个给 Codex / Agent 用的中文改写 Skill。主要用途很简单：把中文里那些一眼能看出“模型整理过”的表达收一收，同时尽量不碰原来的事实、数据、术语和逻辑。

它会特别留意几类问题：

- `不是……而是……`、`不仅……更……` 这类过于工整的转折
- `逐步 / 持续 / 进一步 / 核心` 一类反复出现的修饰词
- `沉淀 / 协同 / 赋能 / 生态 / 闭环 / 壁垒 / 底座` 等容易堆成一团的抽象词
- 连续三段式、排比式表达
- 每段最后都再总结一次、再“升华”一次
- 句子逻辑过满，一句话同时塞进背景、动作、价值和长期结果

商业计划书、报告、科研材料、公众号文章、演讲稿、邮件都可以用。科研、技术和法律文本里确实需要的转折和限定会保留，不会为了“自然”把逻辑改坏。

## 怎么用

把这个仓库作为 Skill 提供给支持 `SKILL.md` 的 Codex / Agent 环境，然后直接说你想怎么改。例如：

```text
请用 chinese-humanizer-skill 修改这份中文商业计划书。不要改事实和数据，重点处理强行转折、抽象词和结尾升华，并给我一份修改报告。
```

也可以更简单：

```text
这段 AI 味有点重，帮我改自然一点，逻辑别动。
```

## 修改报告

有实质性改写时，Skill 默认会在正文后附一份简短报告，通常只写几项：

- 主要发现了什么问题
- 哪些句式或高频词被处理了
- 一两个有代表性的修改
- 哪些专业表达是有意保留的
- 还有没有需要作者自己判断的地方

如果只想要修改后的正文，可以直接说“不要修改说明”。详细格式放在 [`references/edit-report.md`](references/edit-report.md)。

## 扫描脚本

仓库里有一个简单的文本扫描脚本，当前支持 `.txt` 和 `.md`：

```bash
python scripts/scan_ai_tone.py your-document.md
```

它主要用来找高风险句式和看词频，也可以拿来比较修改前后的变化。扫描结果只是编辑参考，不代表 AI 检测结论。

```text
references/sources.md          # 参考来源

```

## 一个小例子

原句：

> 这次更新不仅提升了用户体验，更进一步完善了产品能力，并为后续业务增长奠定了坚实基础。

可以改成：

> 这次更新简化了操作步骤，也补上了几个长期存在的功能缺口。后续是否能带来增长，还要看实际使用数据。

前一句的问题主要是转折、程度副词和结尾升华叠在了一起，信息反而不够具体。
