# Chinese Humanizer Skill

一个面向中文文档的 Codex / Agent Skill，用于降低公式化、模板化的 AI 写作痕迹，同时尽量保留原文事实、术语、结构、语气和专业度。

它不是“同义词替换器”，也不以绕过 AI 检测为目标。重点处理的是中文文本中常见的机械感：强行转折、连接词过密、抽象商业词堆叠、过度工整的三段式、每段都总结升华，以及“逐步 / 持续 / 进一步 / 核心 / 沉淀 / 协同”等高频模板词。

## 能做什么

- 识别并改写 `不是……而是……`、`不仅……更……` 等高风险模板句
- 对高频连接词、抽象词和商业黑话做限频检查
- 优先把“沉淀能力 / 构建生态 / 形成壁垒”改成可观察的动作或结果
- 保留科研、法律、技术文档中真正必要的逻辑转折
- 支持商业计划书、报告、科研材料、公众号、演讲、邮件等中文文体
- 修改完成后默认输出一份简短的“修改报告”，说明主要处理了哪些问题

## 仓库结构

```text
SKILL.md                       # 主 Skill 规则
agents/openai.yaml             # Agent 元数据
references/rulebook.md         # 详细规则表
references/examples.md         # 修改前后示例
references/sources.md          # 参考来源
references/edit-report.md      # 修改报告格式
scripts/scan_ai_tone.py        # AI 腔风险扫描脚本
```

## 使用方式

将本仓库作为 Skill 提供给支持 `SKILL.md` 的 Codex / Agent 环境。触发方式可以很自然，例如：

```text
请用 chinese-humanizer-skill 修改这份中文商业计划书，保留事实和结构，降低 AI 腔，并给我一份修改报告。
```

或者：

```text
去一下 AI 味，不要改事实。重点检查强行转折、逐步/持续/进一步、抽象商业词和结尾升华。
```

### 先扫描再改

对于 `.txt` 或 `.md` 文件，可先运行：

```bash
python scripts/scan_ai_tone.py your-document.md
```

扫描结果用于定位高风险模式和比较修改前后的变化，不用于判断作者身份，也不代表任何 AI 检测结论。

## 修改报告

完成改写后，Skill 默认附一份简版报告，包括：

- 主要命中的 AI 腔类型
- 处理过的高频词或句式
- 代表性修改示例
- 是否保留了必要的专业逻辑与术语
- 修改后仍值得人工确认的地方

详细格式见 [`references/edit-report.md`](references/edit-report.md)。

## 设计原则

1. **事实优先**：不为了“像人写”而虚构例子、数据或经历。
2. **具体优先**：能写“增加合作医院”，就少写“构建资源生态”。
3. **逻辑优先**：真正表达因果、排除、限定关系的转折可以保留。
4. **段落优先**：必要时整段重写，而不是机械替换单词。
5. **不过度润色**：自然不等于口语化，也不等于每句话都必须漂亮。
